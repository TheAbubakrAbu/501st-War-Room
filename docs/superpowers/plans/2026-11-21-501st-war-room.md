# 501st War Room Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go Discord bot that keeps the Helldivers 2 Galactic War map, Major Order and busiest fronts in one auto-edited message, with lookup commands, for the 501st's server.

**Architecture:** One background poller fetches the war every 5 minutes (community API first, Arrowhead's official API as backup), builds an immutable `war.Snapshot`, draws the map PNG once, and swaps both in with one atomic store. Commands only read that state. A war-room manager edits each server's message after every round and posts new Major Orders once.

**Tech Stack:** Go 1.27, `github.com/bwmarrin/discordgo` v0.29.0, `golang.org/x/image` v0.48.0 (vector rasterizer, opentype, Go fonts), standard library for everything else (`net/http`, `encoding/json`, `image/png`, `log/slog`, `testing/synctest`).

**Spec:** `docs/superpowers/specs/2026-11-21-501st-war-room-design.md` (section numbers below, like "spec 4.1", point into it).

## Review Focus

Failure modes the spec implies but no feature test would naturally hit, most likely first. Each has a test in the task named.

1. **Editing the war room must replace the map, not add to it.** An edit without `attachments: []` keeps the old image beside the new one. Test `TestEditReplacesMap` (Task 10).
2. **A Discord outage must not erase a server's war room.** A guild delete event with `unavailable: true` means an outage, not a removal. Test `TestForgetKeepsSettingsDuringOutage` (Task 12).
3. **An order whose end time has passed must not show as current or be announced**, which happens when the feeds are down for hours. Tests `TestBriefingHidesEndedOrder` (Task 10) and `TestUpdateSkipsEndedOrders` (Task 12).
4. **Switching sources mid-order must not announce it again.** Both sources must give the order the same ID. Test `TestOfficialOrderIDMatchesCommunity` (Task 5).
5. **Planet search ignores case and accents:** "popli" finds "Pöpli IX", "ZEA" finds "Zea Rugosia". Test `TestSuggestFoldsCaseAndAccents` (Task 11).
